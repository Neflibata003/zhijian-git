# 纸笺 Git 使用说明

> 给文件夹留下每一个版本。不用记命令，改坏了随时回到从前。

---

## 一、它是什么？能用来干什么？

想象你在写一篇长文章。你会担心：

- 改着改着**改坏了**，想回到昨天的样子；
- 想**试一个大改动**，又怕回不来；
- **不小心删了**一段，才发现没有备份；
- 想把文章**备份到网上**，或者**和别人一起写**。

纸笺 Git 就是解决这些问题的工具。它给你的文件夹拍“存档快照”（叫**版本**），每个版本都记得当时所有文件的样子。它适合：

| 你是… | 可以用来… |
|---|---|
| 写小说、论文、报告的人 | 保存每一稿，随时对比、回到旧稿 |
| 做设计、排版的人 | 给每个阶段存档，方便回退（图片、Word、PDF 也能存档） |
| 写代码的人 | 管理代码版本，开分支试验，备份到 GitHub / Gitee |
| 整理资料的人 | 记录每次调整，找回不小心删掉的内容 |

> 它使用你电脑上的 **Git**（业界通用的版本管理工具），你不需要懂 Git 的命令。

## 二、安装与打开

**需要什么**

- Windows 10 / 11。
- 你的电脑里要装有 **Git for Windows**（官网 https://git-scm.com/download/win ）。没有的话，程序打开时会告诉你并给出链接。
- **WebView2**：Windows 11 自带；Windows 10 安装包已内置引导，装的时候会自动处理。
- **不需要注册账号，不需要联网**。只有“下载安装 Git”和“备份到网上”时才需要网络。

**怎么打开**

1. 双击桌面上的「**纸笺 Git**」快捷方式。
2. 或者：在任意**文件夹上点右键 → 「Git 代码仓库」**，会直接用纸笺 Git 打开这个文件夹。
   （Windows 11 里如果没看到，请点右键菜单最下面的“**显示更多选项**”。）

---

## 三、第一次使用：三步保存你的第一个版本

1. **选择文件夹**：点「添加文件夹」，选你想管理的文件夹。第一次会问“在此创建仓库”——点它。这只会在文件夹里多一个隐藏的 `.git` 文件夹，**不会改动你的文件，也不会上传任何东西**。
2. **勾选并写一句说明**：在「修改」页勾选要保存的文件，在下面写一句话，比如“完成第一章初稿”。
3. **点「保存版本」**。完成！你随时可以在「历史版本」里看到它。

> 第一次保存时，程序会请你填写“姓名和邮箱”，用来记录是谁保存的。**只保存在这个文件夹里，邮箱不必真实。**

## 四、每个功能是做什么的

每个页面顶部都有一张「这是什么」的小卡片，看懂后点右上角 ✕ 就不再出现。右上角的 **？** 按钮随时可以打开“使用帮助”（场景 + 名词解释）。

### 1. 修改（保存版本）

- 列出你**改过、新建、删除**的文件。**勾选**＝挑进下一个版本；没勾的不会被保存。
- **已准备保存**：已勾选的文件；**尚未准备保存**：还没勾的。
- 点文件名，右边显示**这个文件改了什么**：绿色是新增，红色是删除。可切换“统一 / 左右对照”。
- 鼠标移到某一块修改的标题栏，会有「**准备此块**」按钮——只保存这一小块，同一个文件的其他修改先不保存。
- **放弃修改**：把一个文件恢复成上次保存的样子。⚠️ 这些未保存的修改会**永久丢失**，所以会先让你确认，并告诉你影响多少行。
- **修改上一次保存**：刚保存完发现漏了文件、或说明写错了？勾上它就能补救（只适合还没上传的最近一次保存）。
- **逐行追溯**：看文件里每一行是谁、在哪次保存里改的。
- **二进制文件**（Word、PDF、图片）：能保存、能看历史，但不会显示逐行对比，只提示“不支持文本差异预览”，并可打开文件或导出历史副本。

### 2. 历史版本

- 每次保存都会留下一条记录，最新的在最上面。可以按**说明**或**作者**搜索。
- 点一条：看当时改了哪些文件、改了什么。
- **撤销这次保存**：新增一个“反向”版本来抵消它，历史记录原样保留——**最安全的撤销**。
- **撤销上次保存（保留修改）**：只对最新一次、还没上传的保存可用。撤销后文件里的内容都在，回到“已准备保存”。
- **回到此版本…**：把当前分支退回过去。默认“保留修改”（只移动记录，文件不变）；选“彻底回到”会丢弃之后的内容，需要**输入分支名**确认。
- **复制到当前分支**：把某一次保存单独挑过来。
- **贴标签**：给版本起一个永久的名字，比如“v1.0 定稿”。

### 3. 分支

- **分支**像一条平行的“草稿线”：想试新点子，就新建一条，随便改，不影响主线。
- 满意了：切回主分支，选中试验分支，点「**合并到当前分支**」。不满意：直接删掉这条分支。
- **切换**分支时，如果你还有没保存的修改，程序会问你：先“**收进暂存修改**”再切换，你的内容不会丢。
- 如果你当前“不在任何分支上”（游离 HEAD），切走前程序会提醒你：先「在此创建分支」保住最近的版本。
- 下方还有**标签**列表，可以新建、删除标签。

### 4. 暂存修改（抽屉）

- 写到一半，要先处理别的事？点「**暂存当前修改**」，所有未保存的修改（含新文件）被收进“抽屉”，文件夹回到干净。
- 之后选中那条记录，点「**恢复**」或「**恢复并清理**」，就能接着写。
- 注意：它和“已准备保存”是两回事。

### 5. 远程同步（顶部那一条）

远程仓库是放在网上的副本（GitHub、Gitee 等），用来**备份**和**协作**。

- 没连接时，点「**连接远程仓库…**」，把网站上仓库的网址粘贴进去。
- **获取更新**：只看看远程有什么新东西，不改你的文件，很安全。
- **拉取**：把远程的新版本合并进来。有未保存的修改时会要求你先处理。
- **上传**：把你本机保存的版本送到远程。
- 两个小数字：↑ 是“你有几个版本还没上传”，↓ 是“远程有几个新版本还没拉取”。
- 🔒 **安全承诺**：本程序**永远不会强制上传**（不会覆盖别人的成果）；**不保存你的密码或令牌**——登录由 Windows 自带的“Git 凭据管理器”弹窗完成，网址里也不允许写入它们。
- 出错时会告诉你原因：登录失败、网络不通、远程有新版本被拒绝、出现冲突。

### 6. 冲突（两边改了同一个地方）

合并或拉取时，如果两边改了同一处，Git 不知道该留谁的，就会出现“冲突”，程序会自动带你到「修改」页：

- **保留我的** / **采用对方的**：整个文件二选一。
- **手动编辑**：打开文件，找到 `<<<<<<<` 和 `>>>>>>>` 标记，改成你想要的内容并删掉标记，保存后点「**标记为已解决**」。
- 全部解决后，顶部的黄色条上点「**继续**」完成合并；想放弃这次合并，点「**中止操作**」，一切回到合并之前。

### 7. 从网址克隆

侧栏的「**从网址克隆**」：把网上已有的仓库完整下载到电脑。选好保存位置即可，需要登录时会弹出 Windows 的登录窗口。

### 8. 操作记录（后悔药）

按 **Ctrl+K**，输入“操作记录”。Git 悄悄记着你每次移动到过的位置，误操作后可在这里“回到这一步”。

### 9. 命令面板与外观

- **Ctrl+K**：命令面板，输入关键词快速做事（刷新、切换页面、切换项目、切换主题……）。
- 右上角 🌙/☀️：浅色 / 深色主题。
- 三栏之间的分隔线可以**拖动**调整宽度，程序会记住。
- **Ctrl+Enter**：在说明框里快速保存版本。

## 五、安全与放心

- **保存版本只发生在你的电脑里**，不会上传。只有你点“上传”才会离开本机。
- 所有会**丢失内容**的操作（放弃修改、彻底回到、删除未合并的分支、丢弃暂存记录）都会先弹出确认，并说明会发生什么。
- “从列表移除项目”**不会删除**任何文件或版本记录。
- 程序不会在后台反复运行 Git：只在你操作后、窗口重新获得焦点时、以及文件发生变化时刷新。

## 六、常见问题

**Q：提示“没有找到 Git”？**
A：先安装 Git for Windows（https://git-scm.com/download/win ），装好后点“重新检测”。

**Q：我把文件夹放在别的仓库里了？**
A：为避免嵌套，程序会提示“这个文件夹位于另一个仓库里”，你可以打开上级仓库。

**Q：点“上传”提示登录失败？**
A：确认账号有权限；第一次会弹出 Git 凭据管理器登录窗口，登录一次即可。

**Q：右键菜单里没有“Git 代码仓库”？**
A：Windows 11 请点“显示更多选项”。如果仍没有，请用安装包重新安装一次。

**Q：怎么卸载？**
A：Windows 设置 → 应用 → 找到“纸笺 Git”卸载，右键菜单项会一并清除；你的项目文件夹和版本记录不受影响。

## 七、已知限制（如实说明）

- 界面目前只有**中文**，没有英文版。
- 没有托盘常驻、没有自动更新。
- 不支持**交互式变基**的拖拽重排，也不支持按**单行**暂存（可按“代码块”暂存）。
- 冲突只能“整个文件二选一”或手动编辑，暂不支持逐块可视化选择。
- 不提供**强制上传**（这是有意为之）。
- 合并版本（有两个来源的版本）不能被“撤销这次保存”或“复制”。
- 非常大的文本差异会限制预览（超过约 512KB 时提示，可手动继续加载）。
